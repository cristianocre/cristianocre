Para quem é

Para quem trava na hora de transformar conceito em anúncio

O curso foi feito para quem entende o que é uma campanha, mas não sabe qual estrutura escolher, quanto investir, quando escalar e como saber se o resultado foi bom.

Serve para os dois lados do balcão. Para quem opera a mídia e quer parar de decidir no achismo, e para quem contrata e precisa saber avaliar o trabalho de uma agência ou de um gestor de tráfego pelo indicador certo.

Não serve para quem procura fórmula pronta de faturamento nem para quem quer alguém executando no lugar dele. Nesses casos, o caminho honesto é outro: treinar o time ou contratar execução.
